## 2. أوامر التشغيل (من مجلد tender-platform)

```bash
# جمع الفرص من المصادر وتحديث الأرشيف
python3 scraper/run.py

# استيراد دفعة CSV يدوية (بإزالة تكرار تلقائية)
python3 scraper/import_csv.py path/to/file.csv "اسم المصدر"

# بناء الموقع (dist/index.html للنشر، preview.html بخط مضمّن)
python3 site/build.py
python3 site/build.py --inline-font path/to/NotoKufiArabic.woff2

# تشغيل البوت (يقرأ TG_TOKEN من البيئة)
export $(grep -v '^#' .env | xargs) && python3 bot/bot.py

# إرسال تنبيهات الجديد فقط للمشتركين (يُشغَّل بعد كل جمع)
export $(grep -v '^#' .env | xargs) && python3 bot/notify.py
```

## 3. خريطة الكود

- `scraper/sources/` — جامع لكل مصدر (wenak، tender4arab) — إضافة مصدر = ملف جديد بنفس الواجهة (`SOURCE`, `LIST_URL`, `parse()`).
- `scraper/normalize.py` — التصنيف (12 قطاعاً)، وسم المنطقة/المدن، توحيد التواريخ. **أي تعديل تصنيف يبدأ هنا.**
- `scraper/run.py` — المشغّل: يجمع، يوحّد، يدمج مع الأرشيف (لا يفقد القديم أبداً).
- `data/tenders.json` — الأرشيف الكامل (أصل تجاري: يغذي نتائج الترسية ومؤشر الأسعار لاحقاً).
- `data/subscribers.json` + `data/notified_ids.json` — بيانات تشغيل البوت، **خارج git** (خصوصية المشتركين).
- `site/template.html` + `site/build.py` — الموقع (هوية v2: منت + Noto Kufi Arabic).
- `bot/` — بوت الاشتراك (bot.py)، مرسل التنبيهات (notify.py)، طبقة API (tg.py)، التخزين (store.py).
- `docs/phase0-study.md` — الدراسة والقرارات والمراحل وسجل أفكار المالك المعتمدة.
- `docs/jobsps-baseline.md` — تحليل خط الأساس (jobs.ps) وقرارات الوراثة والتفوق.

## 4. قرارات ثابتة (لا تُعاد مناقشتها بدون قرار مالك)

1. غزة أولاً؛ الفصل الجغرافي حسب **مكان التنفيذ** لا الناشر.
2. jobs.ps **ليس** مصدر جمع آلي (محتواه التجاري) — يُقبل استيراد ملفات يدوية من المالك، مع محاولة الوصول للإعلان الأصلي وإلا فرابط جوبس.
3. الروابط دائماً للمصدر الأصلي — نحن دليل، والتقديم عند الجهة الناشرة.
4. واتساب = قناة واحدة يدوية بملخص يومي مولّد آلياً؛ تيليجرام = الأتمتة الكاملة والفلترة.
5. الدفع مؤجل للمرحلة 2 (بعد 500–1,000 متابع): اشتراكات بالمحفظة الإلكترونية.
6. التوسع الأفقي (أفراد) = منصة منفصلة بالبراند على نفس المحرك (نموذج Freepik/Flaticon).
