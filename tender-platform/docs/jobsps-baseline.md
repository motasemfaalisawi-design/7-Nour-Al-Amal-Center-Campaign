# تحليل خط الأساس: صفحة عطاءات جوبس (jobs.ps/tenders)

*تحليل بنيوي خارجي من ملف HTML قدمه المالك — 2026-07-06. الغرض: خريطة ميزات مرجعية. لا يُنسخ أي كود أو نص أو تصميم من المصدر.*

## بنية صفحة القائمة

- **20 عطاءً بالصفحة**، مع ترقيم صفحات يصل لمئات الصفحات (أرشيف ضخم — قيمة الأرشيف التاريخي مثبتة سوقياً).
- **الصف الواحد نحيف جداً**: عنوان + مدينة + تاريخ إغلاق مختصر (مثل "12, Jul") + سهم للتفاصيل. لا جهة ناشرة ولا قطاع ظاهرين في القائمة.
- **شعارات مميزة (featured logos)**: ~15 شعار جهة بمكان بارز — نمط تسييل/ثقة (الجهات تدفع للظهور).

## الفلاتر والتصنيف

- **41 فئة قطاعية** كمربعات اختيار متعددة (multi-select checkboxes) — تصنيف غني جداً (هندسي، طبي، طاقة متجددة، تعليم، ضيافة، موارد بشرية...).
- **فلتر مواقع بمستوى المدينة**: 26 مدينة (رام الله والبيرة، القدس، قطاع غزة، الخليل، نابلس...) — غزة كلها خانة واحدة عندهم.
- بحث نصي علوي عام (وظائف/شركات/مقالات).

## أقسام الموقع المحيطة

عطاءات، وظائف، شركات/صفحات شركات، تدريب، مقالات، تنبيهات وظائف (بريدية)، نسخة إنجليزية كاملة (/en)، RSS.

## قرارات مستخلصة لمنصتنا («توريد»)

| الملاحظة عندهم | قرارنا |
|---|---|
| صف القائمة نحيف (عنوان+مدينة+تاريخ) | نتفوق بحكمة: نضيف الجهة والقطاع وعداد "باقي X أيام" مع الحفاظ على قابلية المسح السريع |
| 41 فئة كمربعات اختيار | نعتمد تصنيفاً بمستويين: رقائق (chips) للقطاعات الرئيسية بالواجهة + فلتر كامل متعدد الاختيار بشاشة "كل الفلاتر"؛ نبدأ بـ~12 فئة ونتوسع |
| المواقع بمستوى المدينة و"قطاع غزة" خانة واحدة | نتفوق: داخل غزة نفصّل (غزة، الشمال، دير البلح، خانيونس، رفح) — لأن التنقل داخل القطاع نفسه صعب، والدقة الجغرافية قيمة حقيقية للمورد |
| شعارات الجهات المميزة | نؤجلها لمرحلة دليل الموردين/الجهات الموثقة (تسييل لاحق) |
| تنبيهات بريدية فقط | ثغرتنا الأساسية تتأكد: تيليجرام/واتساب فوري مفلتر لا وجود له عندهم |
| أرشيف بمئات الصفحات | نحتفظ بكل ما نجمعه من اليوم الأول — الأرشيف يتحول لاحقاً لبيانات (نتائج ترسية، مؤشر أسعار) |
| نسخة إنجليزية كاملة | مرحلة لاحقة (مهمة للمنظمات الدولية في المرحلة 3+) |
| عناوين URL وصفية لكل عطاء (slug + رقم) | نعتمد نفس النمط — جيد للأرشفة ومحركات البحث |

## ملاحظة مصادر

جوبس نفسه ليس مصدر جمع لنا: محتواه منشورات مدفوعة من الجهات (ملكه التجاري). مصادرنا تبقى الجهات الناشرة الأصلية والبوابات العامة (UNGM, UNDP, wenak، مواقع المنظمات)، مع حفظ حقائق الإعلان (عنوان، جهة، موعد) والربط للمصدر الأصلي دائماً.
