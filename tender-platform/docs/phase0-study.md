# منصة المناقصات وعروض الأسعار — دراسة المرحلة صفر

*آخر تحديث: 2026-07-05*

## 1. الفكرة باختصار

منصة تجمع آلياً المناقصات وطلبات عروض الأسعار (RFQs) المنشورة علناً، تصنّفها حسب القطاع ومنطقة التنفيذ، وتوزعها كتنبيهات فورية للموردين — مجاناً عبر قناة عامة، وباشتراك مدفوع للتنبيهات المفلترة حسب التخصص.

**نموذج العمل:** self-serve بالكامل — لا حاجة لإقناع جهات بالنشر (المحتوى يُجمع من المصادر العلنية)، والمورد يشترك بنفسه ويدفع بالمحفظة الإلكترونية.

## 2. لماذا الآن؟ (خلاصة دراسة السوق — تموز 2026)

- إعادة إعمار غزة مقدّرة بـ 71 مليار دولار على 10 سنوات؛ حجم مشتريات المنظمات (UNRWA, UNDP, INGOs) كبير ومتصاعد. طلبات عروض الأسعار الصغيرة وحدها 10–200 ألف دولار للطلب.
- المحافظ الإلكترونية هي العملة الفعلية في غزة (83% من التجار يقبلونها) — تسمح باشتراكات مدفوعة self-serve بدون كاش وبدون عمولات تكييش.
- مواقع تجميع العطاءات الموجودة (tender4arab, paltender, wenak.ps) كلها "مواقع تزورها" — **لا أحد يوصل التنبيه للمورد على واتساب/تيليجرام مفلتراً حسب تخصصه. التوزيع هو ثغرتنا التنافسية.**

## 3. قرارات معتمدة

| القرار | الاختيار |
|---|---|
| الجمهور الأول | موردو **غزة** فقط؛ الضفة لاحقاً كمنطقة منفصلة تماماً |
| الفصل الجغرافي | حسب **مكان التنفيذ/التسليم** وليس مكان الناشر (جهات برام الله/عمّان تنشر مناقصات تنفيذها في غزة) |
| قنوات التنبيه (مرحلة 1) | بوت تيليجرام (فلترة لكل مشترك، مجاني) + قناة واتساب (بث عام) |
| الدفع | مؤجل للمرحلة 2؛ المرحلة 1 مجانية بالكامل |
| التوسع الأفقي (أفراد) | **منصة منفصلة بالبراند** على نفس المحرك والبنية (نموذج Freepik/Flaticon) |
| البنية | كل كيان (فرصة/مورد/اشتراك) موسوم بمنطقة منذ اليوم الأول — التوسع الجغرافي إضافة مصادر لا إعادة بناء |

## 4. مراحل التنفيذ وشروط الانتقال

1. **النواة:** جمع آلي + موقع عرض مصنف + قناة مجانية. → *شرط الانتقال: 500–1,000 متابع وتفاعل يومي.*
2. **أول دخل:** تنبيهات مفلترة مدفوعة (اشتراك شهري بالمحفظة) + نتائج الترسية. → *شرط: 50–100 مشترك دافع.*
3. **السوق العكسي:** نشر ذاتي لطلبات عروض الأسعار، الموردون يردون بعروضهم. → *شرط: طلبات أسبوعية تلقائية و3+ عروض للطلب.*
4. **التوسع الأفقي:** منصة الأفراد المنفصلة (اطلب 3 أسعار / تجميع مشتريات / مزادات بيع — واحدة تُختار حسب البيانات) + خدمات مساندة (جهزلي عرضي، عقود تلقائية).
5. **العمق المؤسسي:** مؤشر أسعار السوق كاشتراك مؤسسي + "قسم مشتريات بالإيجار" (SaaS لدورة الشراء كاملة).
